# 📚 Plotz: Sua Rede Social Literária

**Plotz** é uma rede social criada para conectar leitores, fomentar o debate literário e fortalecer a comunidade local através do amor pelos livros.

---

## 📖 Sobre o Projeto
O **Plotz** nasce da ideia de criar um espaço digital dinâmico e interativo para amantes da leitura.  
Diferente de um catálogo formal de livros, a plataforma funciona de maneira similar ao Instagram, onde o foco está na **interação social**, na **criação de conteúdo** e na **troca de experiências**.

O objetivo principal é **combater o declínio do hábito de leitura**, utilizando a força das redes sociais para transformar a leitura em uma atividade mais conectada, engajadora e comunitária.

---

## 🌍 Conexão com os ODS da ONU
Este projeto está alinhado com os Objetivos de Desenvolvimento Sustentável (ODS):

- **ODS 4 - Educação de Qualidade**: Incentivando a leitura e o letramento contínuo.  
- **ODS 10 - Redução das Desigualdades**: Dando voz a diversas narrativas e democratizando o acesso à cultura.  
- **ODS 11 - Cidades e Comunidades Sustentáveis**: Fortalecendo a cultura local ao conectar leitores com bibliotecas e livrarias da sua região.  

---

## ✨ Funcionalidades
- 📌 **Feed Social**: Acompanhe posts e interações das pessoas que você segue.  
- 📝 **Criação de Posts**: Compartilhe fotos, resenhas, citações e reflexões literárias.  
- ❤️ **Interações**: Curta, comente e salve posts de outros leitores.  
- 💬 **Mensagens Diretas**: Converse em particular com outros leitores.  
- 🔄 **Marketplace Comunitário**: Venda, troque ou doe livros.  
- 📍 **Mapa de Bibliotecas**: Encontre bibliotecas públicas e comunitárias em **São José dos Campos e região**.  
- 👤 **Perfis de Usuário**: Crie seu perfil, siga outros leitores e acompanhe suas atividades.

## 🛠️ Tecnologias Utilizadas

### Frontend
- [React](https://react.dev/) → Biblioteca JavaScript para interfaces de usuário.  
- [Tailwind CSS](https://tailwindcss.com/) → Framework CSS para estilização rápida e responsiva.  

### Backend
- [Node.js](https://nodejs.org/) → Ambiente de execução JavaScript no servidor.  
- [Express.js](https://expressjs.com/) → Framework para criação da API RESTful.  

### Banco de Dados
- [MongoDB](https://www.mongodb.com/) → Banco de dados NoSQL orientado a documentos.

## 🚀 Como Executar o Projeto

### Pré-requisitos
- [Node.js](https://nodejs.org/) instalado  
- [MongoDB](https://www.mongodb.com/) em execução local ou na nuvem  

### Passos
```bash
# Clone o repositório
git clone https://github.com/seu-usuario/plotz.git

# Acesse a pasta do projeto
cd plotz

# Instale as dependências do backend
cd backend
npm install

# Inicie o servidor
npm start

# Em outro terminal, instale as dependências do frontend
cd frontend
npm install

# Inicie o frontend
npm run dev
